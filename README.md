# Car Expense Tracker

Prosta aplikacja desktopowa służąca do śledzenia wydatków na naprawy samochodu. 

## Główne funkcjonalności
* **Zarządzanie pojazdami:** Dodawanie i usuwanie samochodów.
* **Koszty eksploatacji:** Dodawanie, edycja i usuwanie wydatków.

## Technologie
Java, Java Swing, Baza danych H2, Maven, JUnit 5

## Uruchamianie
Z zakładki releases na githubie można pobrać instalator .exe który zainstaluje program i stworzy skrót na ekranie głownym.
